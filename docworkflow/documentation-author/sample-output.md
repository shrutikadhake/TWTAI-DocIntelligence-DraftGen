# Using Microsoft 365 Copilot Chat to Learn Basic HTML

## Introduction

In this guide, you'll learn how to use Microsoft 365 Copilot Chat as your personal HTML tutor. By asking Copilot a series of questions, you'll understand HTML fundamentals—including what HTML is, how web pages are structured, and how different heading elements work together. By the end, you'll be able to write your own HTML pages and understand code examples.

This approach is hands-on and conversational, letting you learn at your own pace by asking follow-up questions whenever you need clarification.

## Prerequisites

Before you start, make sure you have:

- **Access to Microsoft 365 Copilot** — This guide uses the Copilot chat interface
- **Familiarity with chat interfaces** — You should be comfortable typing messages and reading responses in a chat application
- **Basic understanding of web concepts** — You don't need to know HTML yet, but it helps to know that websites are made up of code and are displayed in web browsers

> **Note:** If you don't have access to Microsoft 365 Copilot, check with your organization's IT department or Microsoft account administrator.

## Procedure

### Task 1: Open Copilot and Ask About HTML Basics

This task introduces you to Copilot and gets your first answer about what HTML is.

**Step 1: Open Microsoft 365 Copilot**

Launch the Copilot application on your device. You can usually find it in your Microsoft 365 applications menu or on the taskbar.

*Details:* On Windows, look for the Copilot icon in your start menu. On Mac or web-based access, navigate to your Microsoft 365 portal and select Copilot.

**Expected result:** You should see the Copilot chat interface with an empty text box ready for your question.

**Step 2: Ask About HTML**

Type your first question in the chat box: `What is HTML?`

*Details:* Be specific in your question. You can use uppercase or lowercase—Copilot understands both. Press Enter or click Send to submit your question.

**Expected result:** Copilot responds with a definition like: "HTML stands for HyperText Markup Language. It is the standard language used to create web pages." This is your answer to the first question.

---

### Task 2: Request an HTML Page Example

Now that you know what HTML is, ask Copilot to show you what actual HTML code looks like.

**Step 1: Ask for a Basic HTML Example**

Type this question in the chat: `Show me a basic HTML page example.`

*Details:* Copilot will provide code, which might look strange at first—that's normal. You're about to understand what all those tags (like `<html>` and `<body>`) mean.

**Expected result:** Copilot provides a complete HTML page example, including tags like `<html>`, `<head>`, `<title>`, `<body>`, `<h1>`, and `<p>`. The example shows a simple webpage with a title and heading.

**Step 2: Review the Provided Example**

Read through the code example Copilot provided. Look for:
- The opening `<html>` tag at the start
- The `<head>` section with a `<title>`
- The `<body>` section with content like `<h1>` (heading) and `<p>` (paragraph)

*Details:* Don't worry if you don't understand every tag yet—that's the next step. Just get familiar with the structure: opening tags (like `<html>`) and closing tags (like `</html>`).

**Expected result:** You understand that HTML pages have a structure with different sections (`head` and `body`) and that content is wrapped in tags that describe what it is (like `h1` for headings).

---

### Task 3: Learn About Heading Elements

Headings are one of the most important HTML elements. This task explains the difference between h1, h2, and other heading levels.

**Step 1: Ask About the h1 Element**

Type: `Explain the h1 element.`

*Details:* The "h" in h1 stands for "heading." Headings are used to make titles and subtitles in web pages.

**Expected result:** Copilot explains: "The h1 element defines a top-level heading on a webpage." You now know that h1 is the most important heading, typically used for page titles.

**Step 2: Ask About Heading Hierarchy**

Type: `What is the difference between h1 and h2?`

*Details:* Understanding the difference is important because web pages use heading levels to organize content, similar to how a book uses chapter titles and section titles.

**Expected result:** Copilot clarifies: "The h1 element represents the main heading while h2 elements represent subheadings." Now you understand that h1 is for main titles and h2 is for secondary sections.

**Step 3: Understand the Heading Hierarchy**

Think about how this works in practice:
- Use `<h1>` for your page's main title (only one per page)
- Use `<h2>` for major section titles
- Use `<h3>`, `<h4>`, etc. for subsections within those sections

*Details:* This is like outlining a document: your main title is h1, chapter titles are h2, subtopic titles are h3, and so on.

**Expected result:** You can now correctly use h1 and h2 elements in your own HTML pages. You understand that heading elements create a logical hierarchy that helps organize web page content.

---

### Task 4: Generate a Sample Web Page

In this final task, you'll ask Copilot to create a complete, practical example that combines everything you've learned.

**Step 1: Request a Generated Example**

Type: `Generate a sample web page using headings and paragraphs.`

*Details:* Ask Copilot to create something practical—maybe a simple blog post or informational page. This gives you a template you can reference for your own projects.

**Expected result:** Copilot generates a complete HTML page with:
- An `<h1>` as the main page title
- One or more `<h2>` headings for sections
- `<p>` tags for paragraphs of text
- Proper opening and closing tags

**Step 2: Review the Generated Code**

Look at the code Copilot created and identify:
- Where the h1 title is
- Where the h2 section headings are
- How paragraphs are formatted with the `<p>` tag

*Details:* Notice how the heading hierarchy creates a natural flow, with the main title at the top, sections below it, and paragraphs filling in the details.

**Expected result:** You have a practical, working example of HTML that uses all the concepts you've learned. This code can serve as a template when you write your own HTML pages.

### Troubleshooting

**I don't see a response from Copilot after typing my question**
- Make sure you're connected to the internet
- Try clicking the Send button again
- Refresh the Copilot page and try your question again
- Check with your IT department if Copilot is available for your account

**The code example Copilot showed looks confusing or different from what I expected**
- HTML can look different depending on what's being demonstrated—there's no single "correct" way
- Try asking Copilot: "Can you explain this code line by line?" or "Show me a simpler example"
- Remember that you don't need to understand every detail yet—just focus on the overall structure

**I'm getting an error when trying to ask Copilot questions**
- This usually means there's a connection issue or Copilot is temporarily unavailable
- Try closing and reopening Copilot
- Check your internet connection
- If the problem persists, contact your IT support team

**I asked a question but got an unexpected answer**
- Copilot sometimes needs clarification
- Try rephrasing your question more specifically
- Example instead of "Tell me about HTML": "What are the basic elements of an HTML page?"
- You can always ask a follow-up question to clarify
