Using Microsoft 365 Copilot to Learn Basic HTML

Learn how to use Microsoft 365 Copilot as your personal HTML tutor through conversational questions and practical examples.

  • Prerequisites

  • Results & Troubleshooting

Introduction

In this guide, you'll learn how to use Microsoft 365 Copilot as your personal HTML tutor. By asking Copilot a series of questions, you'll understand HTML fundamentals—including what HTML is, how web pages are structured, and how different heading elements work together.

By the end, you'll be able to write your own HTML pages and understand code examples. This approach is hands-on and conversational, letting you learn at your own pace by asking follow-up questions whenever you need clarification.

Prerequisites

Before you start, make sure you have:

  • Access to Microsoft 365 Copilot — This guide uses the Copilot chat interface
  • Familiarity with chat interfaces — You should be comfortable typing messages and reading responses in a chat application
  • Basic understanding of web concepts — You don't need to know HTML yet, but it helps to know that websites are made up of code and are displayed in web browsers
Note: If you don't have access to Microsoft 365 Copilot, check with your organization's IT department or Microsoft account administrator.

Procedure

Task 1: Open Microsoft 365 Copilot and Ask About HTML Basics

This task introduces you to Copilot and gets your first answer about what HTML is.

Step 1: Open Microsoft 365 Copilot
On Windows, look for the Copilot icon in your start menu. On Mac or web-based access, navigate to your Microsoft 365 portal and select Copilot.
✓ Copilot interface is open and ready to accept questions
Step 2: Ask About HTML
Be specific in your question. Type: What is HTML?
✓ Copilot responds with the definition: "HTML stands for HyperText Markup Language. It is the standard language used to create web pages."

Task 2: Request an HTML Page Example

Now that you know what HTML is, ask Copilot to show you what actual HTML code looks like.

Step 1: Ask for a Basic HTML Example
Type in the chat: Show me a basic HTML page example.
✓ Copilot provides a complete HTML page example with tags like <html>, <head>, <body>, <h1>, and <p>
Step 2: Review the Provided Example
Read through the code. Look for the opening <html> tag, the <head> section with a <title>, and the <body> section with headings and paragraphs.
✓ You understand that HTML pages have a structure with different sections and content is wrapped in tags

Task 3: Learn About Heading Elements

Headings are one of the most important HTML elements. This task explains the difference between h1, h2, and other heading levels.

Step 1: Ask About the h1 Element
Type: Explain the h1 element.
✓ Copilot explains: "The h1 element defines a top-level heading on a webpage."
Step 2: Ask About Heading Hierarchy
Type: What is the difference between h1 and h2?
✓ Copilot clarifies: "The h1 element represents the main heading while h2 elements represent subheadings."
Step 3: Understand the Heading Hierarchy
Think about how this works in practice: use <h1> for your page's main title (only one per page), <h2> for major sections, and <h3>, <h4>, etc. for subsections.
✓ You can correctly use h1 and h2 elements in your own HTML pages and understand heading hierarchy

Task 4: Generate a Sample Web Page

In this final task, you'll ask Copilot to create a complete, practical example that combines everything you've learned.

Step 1: Request a Generated Example
Type: Generate a sample web page using headings and paragraphs.
✓ Copilot generates a complete HTML page with proper heading hierarchy and paragraph content
Step 2: Review the Generated Code
Look at the code Copilot created and identify where the h1 title is, where the h2 section headings are, and how paragraphs are formatted with the <p> tag.
✓ You have a practical, working example that you can reference for your own projects

Expected Results

What You Will Accomplish

  • Understand HTML basics and why it's used to create web pages
  • Review actual HTML structure with headings, paragraphs, and proper organization
  • Learn the difference between h1 (main title), h2 (sections), and other heading levels
  • Have sample HTML code from Copilot that you can reference and learn from

Validation Checklist

Troubleshooting

I don't see a response from Copilot after typing my question
  • Make sure you're connected to the internet
  • Try clicking the Send button again
  • Refresh the Copilot page and try your question again
  • Check with your IT department if Copilot is available for your account
The code example Copilot showed looks confusing or different from what I expected
  • HTML can look different depending on what's being demonstrated
  • Try asking Copilot: "Can you explain this code line by line?" or "Show me a simpler example"
  • Remember that you don't need to understand every detail yet—focus on the overall structure
I'm getting an error when trying to ask Copilot questions
  • This usually means there's a connection issue or Copilot is temporarily unavailable
  • Try closing and reopening Copilot
  • Check your internet connection
  • If the problem persists, contact your IT support team
I asked a question but got an unexpected answer
  • Copilot sometimes needs clarification in your question
  • Try rephrasing your question more specifically
  • Instead of "Tell me about HTML" try "What are the basic elements of an HTML page?"
  • You can always ask a follow-up question to clarify

What's Next?

You've completed the basics! Here are some ways to continue learning:

  • Ask Copilot more questions — Try asking about CSS (styling), JavaScript (interactivity), or specific HTML tags
  • Write your own HTML — Use the example Copilot provided as a template and make your own modifications
  • Ask Copilot to review your code — Paste code you wrote and ask for feedback
