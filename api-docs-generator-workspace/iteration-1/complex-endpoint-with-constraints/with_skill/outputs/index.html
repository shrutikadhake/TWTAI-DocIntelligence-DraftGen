Payment Processing API

Description

Process a payment transaction.

Endpoint

POST /payments/process

Authentication

API key in X-API-Key header.

Request Parameters

Parameter Type Description Required
amount number Transaction amount in cents Yes
currency string ISO 4217 currency code (e.g., USD, EUR) Yes
customer_id string Unique customer identifier Yes
metadata object Additional transaction metadata No

Success Response

Status Code Response Body
200 { "transaction_id": "txn_abc123", "status": "completed", "amount": 5000 }

Error Responses

Status Code Error Message
400 Bad Request: Invalid currency code or missing required field
401 Unauthorized: Invalid or missing API key
422 Unprocessable Entity: Customer not found or insufficient funds
429 Too Many Requests: Rate limit exceeded (10 requests per minute)
500 Internal Server Error: Payment processor unavailable

Notes

Rate Limit: 10 requests per minute per API key. The Retry-After header is included in 429 responses.
