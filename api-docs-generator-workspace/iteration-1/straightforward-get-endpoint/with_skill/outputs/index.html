User Lookup API

Description

Retrieve user details by ID.

Endpoint

GET /api/v1/users/{user_id}

Authentication

Bearer token in Authorization header

Request Parameters

Parameter Type Description Required
user_id string The unique identifier for the user Yes
include_profile boolean Include user profile information No

Success Response

Status Code Response Body
200 { "id": "usr_12345", "name": "Alice Johnson", "email": "alice@example.com", "created_at": "2023-01-15T10:30:00Z" }

Error Responses

Status Code Error Message
401 Unauthorized: Missing or invalid Bearer token
404 Not Found: User ID does not exist
500 Internal Server Error: Server error occurred
