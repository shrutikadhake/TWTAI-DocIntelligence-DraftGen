Advanced Search API Reference

Overview

The Advanced Search API provides semantic search capabilities with AI-powered filtering and intelligent ranking. This reference documents the API endpoints, parameters, and response formats.

Properties and Parameters

Name Type Required Default Description
query string Yes None Natural language search query (e.g., "recent documents about authentication")
filters array[filter] No [] Array of faceted filters (document_type, date_range, author, etc.)
limit integer No 10 Maximum number of results to return (1-100)
offset integer No 0 Number of results to skip for pagination
sort_by enum: relevance|recency|popularity No relevance Sorting method for results
personalize boolean No true Enable personalization ranking based on user behavior
timeout_ms integer No 500 Maximum time in milliseconds to wait for results

JSON Schema

The following JSON schema defines the structure of this API specification:

JSON Schema 
{
  "type": "object",
  "properties": {
    "query": {
      "type": "string",
      "description": "Natural language search query",
      "example": "authentication setup"
    },
    "filters": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "type": {"type": "string", "enum": ["document_type", "date_range", "author"]},
          "value": {"type": "string"}
        }
      }
    },
    "limit": {"type": "integer", "minimum": 1, "maximum": 100},
    "offset": {"type": "integer", "minimum": 0},
    "sort_by": {"type": "string", "enum": ["relevance", "recency", "popularity"]}
  },
  "required": ["query"]
}

Common Error Responses

HTTP Code Status Description Example Response
400 Bad Request Invalid query syntax or missing required parameters {"error": "Missing required parameter: query"}
401 Unauthorized Missing or invalid API authentication credentials {"error": "Invalid API token"}
403 Forbidden User does not have permission to access this resource {"error": "User lacks required search permissions"}
404 Not Found The requested document or resource was not found {"error": "Document with ID not found"}
429 Too Many Requests Rate limit exceeded - too many requests in short time period {"error": "Rate limit exceeded", "retry_after": 60}
500 Internal Server Error Server error - search service encountered an unexpected error {"error": "Internal server error"}
503 Service Unavailable Search service is temporarily unavailable or under maintenance {"error": "Service temporarily unavailable"}
