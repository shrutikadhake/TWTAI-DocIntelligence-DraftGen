Employee Onboarding API

Description

Create a new employee record in the HR system.

Endpoint

POST /employees

Authentication

Bearer token

Request Parameters

Parameter Type Description Required
first_name string Employee's first name Yes
last_name string Employee's last name Yes
email string Employee's email address Yes
department string Employee's department No

Success Response

Status Code Response Body
201 { "id": "employee_id", "first_name": "string", "last_name": "string", "email": "string", "department": "string" }

Error Responses

Status Code Error Message
400 Bad Request: Invalid request
401 Unauthorized: Authentication failed
409 Conflict: Employee already exists
500 Internal Server Error: Server error
