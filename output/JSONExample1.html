Bulk User Import

Overview

Import multiple users into the application using a CSV file. This feature is available to administrators.

Prerequisites

  • Administrator role
  • Valid CSV file

Procedure

  1. Navigate to User Management.
  2. Select Import Users.
  3. Upload the CSV file.
  4. Review validation results.
  5. Click Import.

Notes

  • Duplicate users are skipped.

Warnings

  • Invalid rows are not imported.
