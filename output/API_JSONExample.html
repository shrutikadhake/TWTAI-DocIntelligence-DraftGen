Create User APIEnterprise User Management Service v2.1

Product: Enterprise User Management Service

Version: v2.1

Base URL: https://api.example.com

Overview

Creates a new user account in the Enterprise User Management Service. The API returns the created user details upon successful completion.

Endpoint

POST /v2/users

Full URL: https://api.example.com/v2/users

Authentication

This endpoint requires Bearer token authentication.

Header: Authorization: Bearer <access_token>

Authentication Type: Bearer Token

Permissions

The authenticated user must have the following permission:

  • User.Create

Request

Headers

Include the following headers in your request:

Header Name Value Required
Authorization Bearer <access_token> Yes
Content-Type application/json Yes

Body Parameters

Send the following JSON object in the request body:

Parameter Type Description
firstName string The user's first name (required).
lastName string The user's last name (required).
email string The user's email address. Must be unique (required).
department string The user's department.
role string The user's role. Must exist in the system (required).
active boolean User account status. Default is true.

Query Parameters

Optionally include the following query parameters:

Parameter Type Required Description
sendWelcomeEmail boolean No Sends a welcome email after the user account is created.

Example Request

POST https://api.example.com/v2/users?sendWelcomeEmail=true HTTP/1.1
Authorization: Bearer YOUR_ACCESS_TOKEN
Content-Type: application/json

{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john.doe@example.com",
  "department": "Engineering",
  "role": "Developer",
  "active": true
}

Response

Success Response

201 Created — User created successfully.

{
  "userId": "USR-10245",
  "status": "Created",
  "createdDate": "2026-07-03T10:30:00Z"
}

Error Responses

The following error responses indicate a failed request:

Status Code Error Description
400 Bad Request One or more required fields are missing or invalid.
401 Unauthorized Authentication token is missing or invalid.
403 Forbidden The authenticated user does not have permission to create users.
409 Conflict A user with the specified email address already exists.

Validation Rules

Your request must comply with the following validation rules:

  • Email address must be unique.
  • First Name is required.
  • Last Name is required.
  • Role must exist in the system.

Rate Limiting

API requests are subject to the following rate limit:

  • Limit: 100 requests per minute
  • Retry After: 60 seconds

If you exceed the rate limit, the API returns a 429 Too Many Requests response. Wait the specified time before retrying your request.

Notes

  • User IDs are generated automatically.
  • Email addresses are stored in lowercase.

Warnings

Security Consideration

Do not expose access tokens in client-side code.

Separate Operation

Deleting a user is a separate operation. Use the Delete User API endpoint.
