Create User API

Overview

Creates a new user account in the Enterprise User Management Service (version v2.1). The API returns the created user details upon successful completion.

Endpoint

Base URL: https://api.example.com

Path: POST /v2/users

Authentication

Use Bearer token authentication. Include your access token in the Authorization header.

Authorization: Bearer <access_token>

Permissions

  • User.Create

Request

Headers

Header Value Required
Authorization Bearer <access_token> Yes
Content-Type application/json Yes

Parameters

Parameter Type Required Description
sendWelcomeEmail Boolean No Sends a welcome email after the user account is created.

Request Body

{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john.doe@example.com",
  "department": "Engineering",
  "role": "Developer",
  "active": true
}

Example Request

POST https://api.example.com/v2/users?sendWelcomeEmail=true
Content-Type: application/json
Authorization: Bearer <access_token>

{
  "firstName": "John",
  "lastName": "Doe",
  "email": "john.doe@example.com",
  "department": "Engineering",
  "role": "Developer",
  "active": true
}

Response

Success Response

Status Code: 201 Created

Description: User created successfully.

{
  "userId": "USR-10245",
  "status": "Created",
  "createdDate": "2026-07-03T10:30:00Z"
}

Error Responses

Status Code Error Description
400 Bad Request One or more required fields are missing or invalid.
401 Unauthorized Authentication token is missing or invalid.
403 Forbidden The authenticated user does not have permission to create users.
409 Conflict A user with the specified email address already exists.

Validation Rules

  • Email address must be unique.
  • First Name is required.
  • Last Name is required.
  • Role must exist in the system.

Rate Limiting

Limit: 100 requests per minute

Retry After: 60 seconds

Notes

  • User IDs are generated automatically.
  • Email addresses are stored in lowercase.

Warnings

  • Deleting a user is a separate operation.
  • Do not expose access tokens in client-side code.
