Employee Onboarding API

Create new employee records in the HR system

Endpoint

POST /employees

Description

Create a new employee record in the HR system.

Authentication

You must provide a Bearer token to authenticate requests. Include the token in the Authorization header.

Request parameters

Include the following parameters in the request body:

Parameter Type Required Description
first_name string Required Employee's first name
last_name string Required Employee's last name
email string Required Employee's email address
department string Optional Employee's department

Success response

The API returns a 201 status code and the created employee object:

Status code Response
201
{ "id": "emp_123456", "first_name": "John", "last_name": "Doe", "email": "john.doe@company.com", "department": "Engineering" }

Error responses

The API returns one of the following error responses:

Status code Description
400 Bad Request. The request is invalid.
401 Unauthorized. Authentication fails.
409 Conflict. The employee already exists.
500 Internal Server Error. Server error occurred.
