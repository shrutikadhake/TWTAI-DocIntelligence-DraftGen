Connect

The Connect feature allows you to create conformal mesh between the selected entities. This feature is designed to ensure proper mesh continuity and compatibility between adjacent bodies and surfaces in your model.

How to Access

To access the Connect control:

  1. Right-click the Mesh object in the Tree Outline
  2. Click Insert > Connect

Applications

The Connect feature is used when you need to:

  • Create conformal mesh connections between selected entities
  • Ensure mesh continuity between adjacent bodies and surfaces
  • Work with bodies scoped under the Automatic Prime method
  • Ensure all bodies scoped under Weld are meshed together
  • Define connection tolerance for mesh compatibility

UI Options

Suppressed

Description: Suppress the Connect control. When set to Yes, the Active field displays the status of the Connect control.

Default Value: No

Multiple Connection Steps

Description: Enable multiple values for connection tolerance to be applied in sequential steps.

Default Value: No

Application: When enabled, allows you to provide multiple tolerance values for progressive connection refinement.

Connection Tolerance

Description: Specify the tolerance value for connection. When Multiple Connection Steps is set to Yes, you can provide multiple connection tolerance values.

Available Options:

  • Single Tolerance Value: Applies a single tolerance for all connection operations
  • Connection Tolerance List: Specify any number of connection tolerance values separated by a space. The first value in the list performs face-to-face intersections, short edge removal, and thin face removal. From the second tolerance value onwards, only the unconnected (free) edges are considered for performing connections.

Connection Size

Description: Specify the size with which you discretize the edges before connecting them.

Default Value: Element Size

Connection Option

Description: Select the connect option that best suits your meshing requirements.

Available Options:

  • All to All: Connect all edges to all other edges within the tolerance
  • Free to All: Connect only free (unconnected) edges to all other edges
  • Free to Free: Connect only free edges to other free edges

Limitations

Important: Files having partially saved mesh may have the previously saved mesh cleared. You may need to regenerate the mesh for the entire model after using the Connect feature.
