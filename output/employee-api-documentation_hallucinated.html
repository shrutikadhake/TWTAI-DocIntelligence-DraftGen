Employee API

REST API for managing employee records in the HR system

Create Employee

Creates a new employee record in the HR system. Use this endpoint during the employee onboarding workflow to initialize employee records with basic information.

POST /employees

Authentication

This endpoint requires Bearer token authentication. Include your authentication token in the request header as follows:

Authorization: Bearer <your_token_here>

Contact your administrator to obtain an authentication token for API access.

Request

Request Headers

Header Type Required Description
Authorization string Required Bearer token for authentication. Format: Bearer <token>
Content-Type string Required Must be application/json

Request Body Parameters

Send a JSON object with the following parameters:

Parameter Type Required Description
first_name string Required Employee's first name. Maximum 100 characters.
last_name string Required Employee's last name. Maximum 100 characters.
email string Required Employee's email address. Must be a valid email format (RFC 5322). Must be unique in the system.
department string Optional Department assignment. If not provided, can be updated later. Maximum 100 characters.

Response

Success Response

Status Code: 201 Created

Returns the created employee object with the following fields:

Field Type Description
id integer Unique identifier for the employee. Auto-generated by the system.
first_name string Employee's first name.
last_name string Employee's last name.
email string Employee's email address.
department string Department assignment. Null if not provided in the request.
created_at string ISO 8601 timestamp indicating when the employee record was created.
Example Success Response:
{ "id": 12345, "first_name": "John", "last_name": "Doe", "email": "john.doe@company.com", "department": "Engineering", "created_at": "2026-07-04T14:30:00Z" }

Error Responses

Status Code Error Type Description Resolution
400 Bad Request The request is invalid or malformed. Verify all required fields are present, correctly formatted, and meet validation constraints. Check that email is in valid format and all strings do not exceed maximum length.
401 Unauthorized Authentication failed. The provided token is invalid, expired, or missing. Ensure the Authorization header is present with a valid Bearer token. Obtain a new token from your administrator if the current token has expired.
409 Conflict An employee with this email already exists in the system. Use a different, unique email address. If this is an existing employee, use the Update Employee endpoint instead.
500 Internal Server Error An unexpected error occurred on the server. Retry the request after a brief delay. If the error persists, contact your system administrator.
Example Error Response (400 Bad Request):
{ "error": "Bad Request", "message": "Field 'email' is invalid. Must be a valid email address.", "status": 400 }
Example Error Response (409 Conflict):
{ "error": "Conflict", "message": "An employee with email 'john.doe@company.com' already exists.", "status": 409 }

Examples

Complete Request Example

cURL
curl -X POST https://api.company.com/employees \ -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." \ -H "Content-Type: application/json" \ -d '{ "first_name": "John", "last_name": "Doe", "email": "john.doe@company.com", "department": "Engineering" }'
JavaScript (Fetch API)
const response = await fetch('https://api.company.com/employees', { method: 'POST', headers: { 'Authorization': 'Bearer YOUR_TOKEN_HERE', 'Content-Type': 'application/json' }, body: JSON.stringify({ first_name: 'John', last_name: 'Doe', email: 'john.doe@company.com', department: 'Engineering' }) }); const data = await response.json(); console.log(data);
Python (requests)
import requests url = 'https://api.company.com/employees' headers = { 'Authorization': 'Bearer YOUR_TOKEN_HERE', 'Content-Type': 'application/json' } payload = { 'first_name': 'John', 'last_name': 'Doe', 'email': 'john.doe@company.com', 'department': 'Engineering' } response = requests.post(url, json=payload, headers=headers) print(response.json())

Complete Response Example (Success)

201 Created Response
{ "id": 12345, "first_name": "John", "last_name": "Doe", "email": "john.doe@company.com", "department": "Engineering", "created_at": "2026-07-04T14:30:00Z" }
Note: Email addresses must be unique across the system. Attempting to create an employee with a duplicate email will return a 409 Conflict error.
Tip: The department field is optional and can be left empty if you plan to assign it later using the Update Employee endpoint.
