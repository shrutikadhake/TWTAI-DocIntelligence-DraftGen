Employee Onboarding API

Create and manage employee records in the HR system

Overview

The Employee Onboarding API enables you to create new employee records in the HR system. This endpoint accepts employee information and returns the created employee object with a unique identifier.

Endpoint

POST /employees

Authentication

Type: Bearer Token
Usage: Include the token in the Authorization header as Bearer {token}

Request Parameters

The request body should contain the following JSON fields:

Parameter Type Required Description
first_name string Yes Employee's first name
last_name string Yes Employee's last name
email string Yes Employee's email address
department string No Employee's department (optional)

Success Response

201 Created Successfully created a new employee record

Response Body:

Status Code Response
201
{ "id": "emp_123456", "first_name": "John", "last_name": "Doe", "email": "john.doe@company.com", "department": "Engineering" }

Error Responses

The API returns standard HTTP error status codes. Refer to the following table for details:

Status Code Error Type Description
400 Bad Request Invalid request payload or missing required fields
401 Unauthorized Authentication failed or invalid bearer token provided
409 Conflict Employee with the provided email already exists in the system
500 Internal Server Error An unexpected error occurred on the server. Please retry the request.
