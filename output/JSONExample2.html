Configure Single Sign-On (SSO)

Overview

Single Sign-On (SSO) enables users to authenticate once and securely access multiple applications without re-entering credentials. This guide covers configuring SSO in Enterprise Access Manager (version 3.2).

Audience

  • System Administrators
  • Identity Administrators

Prerequisites

  • Administrator privileges
  • Access to the Identity Provider (IdP)
  • Metadata XML file from the IdP
  • HTTPS enabled for the application

Permissions

  • Manage Authentication
  • Configure Security Settings

Procedure

  1. Navigate to Administration > Security > Single Sign-On.
  2. Select Enable SSO.
  3. Upload the Identity Provider metadata XML file.
  4. Verify the Entity ID and Assertion Consumer Service (ACS) URL.
  5. Save the configuration.
  6. Perform a test login using an SSO-enabled user account.

Validation

  • Users can authenticate through the Identity Provider.
  • Application dashboard loads successfully after login.
  • No authentication errors are displayed.

Notes

  • Configuration changes may take up to five minutes to propagate.
  • Keep a backup of the previous authentication configuration.

Warnings

  • Incorrect IdP metadata can prevent all users from logging in.
  • Test the configuration before enabling SSO for all users.

Troubleshooting

Issue Resolution
Login fails after SSO is enabled. Verify that the Entity ID and ACS URL match the values configured in the Identity Provider.
Certificate validation error. Confirm that the signing certificate has not expired.
