Learning Basic HTML with Microsoft 365 Copilot Chat

Use Microsoft 365 Copilot Chat to learn HTML basics, generate a working page example, and understand individual HTML elements.

Audience: Anyone new to HTML Requires: Access to Microsoft 365 Copilot Chat Time: ~10 minutes

On this page

  1. Ask Copilot what HTML is
  2. Ask Copilot for a simple HTML example
  3. Explore individual HTML elements
  4. Continue learning with follow-up questions
  5. Expected results

This guide assumes no prior HTML knowledge — you'll pick up what you need directly from Copilot's answers.

Ask Copilot what HTML is

Start with the question anyone new to HTML would ask first — what HTML actually is.

  1. Ask for a definition

    From the Copilot home page, type What is HTML? into the chat box.

    Copilot returns the HTML definition from the introduction.

Ask Copilot for a simple HTML example

A definition is useful, but seeing HTML in action makes it click faster.

  1. Request an example

    Type Show me a simple HTML example.

    Copilot generates a complete HTML page example, including the html, head, title, body, h1, and p elements:

    <html>
<head>
<title>My First Page</title>
</head>
<body>
<h1>Hello World</h1>
<p>This is my first webpage.</p>
</body>
</html>

    Copilot returns the entire page structure, not just a snippet — this gives you a working example you can reference for future pages.

Explore individual HTML elements

Once you have a working example, dig into what each element actually does.

  1. Ask about a specific element

    Type Explain the h1 element.

    Copilot explains that the h1 element defines the primary heading on a web page.

  2. Compare related elements

    Type What's the difference between h1 and h2?

    Copilot explains that h1 represents the primary page heading, while h2 elements create subsection headings.

Continue learning with follow-up questions

Once you understand the basics, use follow-up questions to build more complete pages and understand why the code works the way it does.

  1. Generate a fuller example

    Type Generate a complete HTML page example using headings and paragraphs.

    Copilot generates a fuller HTML page example combining multiple heading and paragraph elements.

  2. Ask Copilot to explain the code

    Type Explain why this code works.

    Copilot explains the purpose and behavior of each element in the generated code, so you understand it rather than just copying it.

Expected results

What you'll have

  • A clear definition of HTML and what it's used for
  • A working HTML page example generated by Copilot
  • An understanding of the h1 and h2 elements and how they differ
  • The ability to keep using follow-up questions to learn new HTML elements on your own

Validation

  • Copilot returned a definition of HTML
  • Copilot generated a complete HTML page example
  • You can explain the difference between h1 and h2
  • You know how to ask Copilot follow-up questions about any HTML element

Troubleshooting

Copilot's answer feels too high-level or vague
  • Ask a more specific follow-up question, such as Explain the h1 element rather than Explain HTML elements.
  • Request an example directly: Show me a simple HTML example.
You don't understand why the generated code works
  • Ask Copilot directly: Explain why this code works.
  • Keep asking follow-up questions about individual elements until each one makes sense.
