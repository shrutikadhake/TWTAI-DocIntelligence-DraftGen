Learning Basic HTML with Microsoft 365 Copilot Chat

Learn how to use Microsoft 365 Copilot Chat to understand HTML basics and generate working page examples.

Audience: New to HTML or web development Requires: Access to Microsoft 365 Copilot Chat Time: About 10 minutes

On this page

  1. Get a Definition of HTML
  2. Generate a Simple HTML Example
  3. Explain Individual HTML Elements
  4. Continue Learning with Follow-up Questions
  5. Expected results

This guide assumes no prior HTML knowledge — you just need access to Microsoft 365 Copilot Chat and basic familiarity with a chat interface.

Get a Definition of HTML

Start from the Copilot home page and ask a foundational question to learn what HTML is before going any further.

  1. Open the Copilot chat box

    Go to the Copilot home page and locate the chat box.

    The chat box is open and ready to accept a question.

  2. Ask what HTML is

    Type What is HTML? into the chat box. HTML stands for HyperText Markup Language — the standard language used to build web pages.

    Copilot responds with an explanation similar to: "HTML stands for HyperText Markup Language. It is the standard language used to build web pages."

Generate a Simple HTML Example

Once you understand what HTML is, ask Copilot to show you a working example so you can see the concept in practice.

  1. Ask for a simple HTML example

    Type Show me a simple HTML example. into the chat box.

    Copilot generates a complete basic HTML page structure:

    <html>
<head>
<title>My First Page</title>
</head>
<body>
<h1>Hello World</h1>
<p>This is my first webpage.</p>
</body>
</html>

Explain Individual HTML Elements

Dig deeper into the example Copilot generated by asking it to explain specific elements, one at a time.

  1. Ask Copilot to explain the h1 element

    Type Explain the h1 element. into the chat box.

    Copilot responds with: "The h1 element defines the primary heading on a web page."

  2. Ask about the difference between h1 and h2

    A common follow-up question once you understand the basics. Type What's the difference between h1 and h2?

    Copilot responds with: "The h1 element represents the primary page heading. h2 elements create subsection headings."

Continue Learning with Follow-up Questions

Build on what you've learned to generate more complete examples and understand why the code works the way it does.

  1. Ask for a complete sample page using headings and paragraphs

    Type Generate a complete sample web page using headings and paragraphs.

    Copilot generates a fuller HTML page example that combines headings and paragraphs into one page.

  2. Ask Copilot to explain why the code works

    Type Explain why this code works.

    Copilot explains the structure and behavior of the generated code. You can keep asking follow-up questions until you understand each element.

Expected results

By completing this guide, you'll have:

  • A clear definition of what HTML is and what it's used for
  • A working HTML example generated by Copilot
  • An understanding of the h1 and h2 heading elements and how they differ
  • The ability to generate and understand a complete sample web page using Copilot

Validation

Troubleshooting

Copilot's response doesn't include code formatting
This can happen if the question is phrased ambiguously.
  • Ask explicitly, e.g., "Show me the HTML code for a simple page," so Copilot recognizes you want a code example.
You don't understand an element Copilot used
This is expected as you're just getting started with HTML.
  • Ask a direct follow-up question, such as "Explain the <p> element," and continue until each part of the example is clear.
