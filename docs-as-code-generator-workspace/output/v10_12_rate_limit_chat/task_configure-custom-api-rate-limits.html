Configure custom API rate limits

Set up custom rate limits for your API by enabling the feature in the global configuration file and applying limits via the CLI.

Prerequisites

  • Root or administrator access to the host server
  • Valid authentication token
  • Latest build deployed to your staging or production environment

Steps

  1. Log into the host server as root.
  2. Open /etc/scanner/config.yml in a text editor.
  3. Locate the api_settings block and set custom_limits_enabled: true, then save the file.
  4. Restart the scanner daemon to apply the configuration change: sudo systemctl restart scanner-daemon
  5. Apply the custom rate limits using the CLI: scanner-cli config update --api-limit <number> --window <seconds>

Expected results

The CLI command returns 200 OK: Rate limits updated. When the rate limit is exceeded, the API responds with 429 Too Many Requests on the next request.

Troubleshooting

Error: 403 Forbidden with message "Rate limit configuration is disabled globally"

You did not enable custom_limits_enabled: true in the api_settings block. Edit the configuration file and set this parameter to true, then restart the daemon.

Configuration changes not taking effect

The scanner daemon does not automatically reload configuration changes. You must restart it after editing /etc/scanner/config.yml using sudo systemctl restart scanner-daemon
