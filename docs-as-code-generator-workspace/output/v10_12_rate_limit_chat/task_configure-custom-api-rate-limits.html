Configure custom API rate limits

Use this procedure to configure custom rate limits for your scanner API. This enables you to enforce request limits on a per-window basis, rejecting requests that exceed your threshold.

Prerequisites

  • Root access to the host server
  • Valid admin authentication token
  • Read and write access to /etc/scanner/config.yml
  • Ability to restart the scanner-daemon service

Steps

  1. Log into the host server as root.
  2. Open /etc/scanner/config.yml in a text editor.
  3. Locate the api_settings block. If it does not exist, add it. Set custom_limits_enabled: true and save the file. 
    api_settings:
  timeout: 30
  custom_limits_enabled: true
  default_limit: 500
  4. Restart the daemon to reload the configuration: 
    sudo systemctl restart scanner-daemon
  5. Apply the custom rate limits using the CLI: 
    scanner-cli config update --api-limit <number> --window <seconds>
    Replace <number> with the maximum number of requests and <seconds> with the time window in seconds (for example, --api-limit 1000 --window 60 allows 1000 requests per 60 seconds).

Expected results

When the configuration is applied successfully, the CLI returns a 200 OK: Rate limits updated. message. Test the rate limit by sending requests to the API endpoint. When you exceed the limit, the API returns a 429 Too Many Requests response.

Troubleshooting

Problem: You receive a 403 Forbidden error with the message Error 403: Rate limit configuration is disabled globally.

Solution: Verify that you completed step 3 and set custom_limits_enabled: true in the api_settings block of /etc/scanner/config.yml. Ensure you saved the file and restarted the daemon in step 4 before running the CLI command.
