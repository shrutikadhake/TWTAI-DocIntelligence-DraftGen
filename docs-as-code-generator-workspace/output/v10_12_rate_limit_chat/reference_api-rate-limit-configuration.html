API rate limit configuration reference

Reference documentation for scanner API rate limit configuration parameters, CLI commands, and error codes.

Configuration file structure

Rate limit settings are stored in /etc/scanner/config.yml under the api_settings block:

api_settings:
  timeout: 30
  custom_limits_enabled: true
  default_limit: 500

Configuration parameters

Parameter Type Description
custom_limits_enabled Boolean Enable or disable custom rate limit enforcement. Set to true to allow custom limit configuration. Set to false to disable custom limits globally.
default_limit Integer The default maximum number of requests allowed within the specified window when no custom limit is set. Example: 500
timeout Integer Request timeout in seconds. Example: 30

CLI command reference

Command: scanner-cli config update

Description: Updates the current rate limit configuration.

Syntax:

scanner-cli config update --api-limit <number> --window <seconds>

Parameters:

Parameter Type Required Description
--api-limit Integer Yes Maximum number of requests allowed within the time window.
--window Integer Yes Time window in seconds within which the limit applies.

Example:

scanner-cli config update --api-limit 1000 --window 60

This example sets a limit of 1000 requests per 60 seconds.

HTTP status codes and error responses

Code Message Description
200 OK Rate limits updated. The rate limit configuration was successfully applied.
403 Forbidden Rate limit configuration is disabled globally. Custom limits are disabled. Set custom_limits_enabled: true in /etc/scanner/config.yml and restart the daemon.
429 Too Many Requests Request rate limit exceeded. The client has exceeded the configured rate limit and the request was rejected.

Service management

Restart the daemon:

sudo systemctl restart scanner-daemon

Configuration changes require a daemon restart to take effect. The daemon does not support hot-reload.
