API rate limit configuration reference

Configuration file

The global configuration file is located at /etc/scanner/config.yml. The rate limit settings are defined within the api_settings block.

api_settings block structure

api_settings:
  timeout: <seconds>
  custom_limits_enabled: <true|false>
  default_limit: <number>
Parameter Type Description
timeout Integer (seconds) Request timeout duration. Requests that exceed this duration are terminated.
custom_limits_enabled Boolean Must be set to true to enable custom rate limit configuration via CLI. If false, CLI commands to set rate limits return a 403 error.
default_limit Integer The default number of requests allowed per window if no custom limit is configured.

CLI command reference

scanner-cli config update --api-limit <number> --window <seconds>

Parameter Type Description Example
--api-limit Integer Maximum number of requests allowed within the specified window. 1000
--window Integer (seconds) Time window in seconds for the rate limit calculation. 60 (one minute)

Response codes

Code Message Condition
200 200 OK: Rate limits updated. Rate limits successfully applied.
403 403 Forbidden: Rate limit configuration is disabled globally. custom_limits_enabled is set to false in the configuration file, or the daemon has not been restarted after enabling it.
429 429 Too Many Requests A client request exceeded the configured rate limit and was rejected. The client may retry after the time window expires.

Daemon restart

After modifying /etc/scanner/config.yml, restart the daemon to load the changes:

sudo systemctl restart scanner-daemon

The daemon does not hot-reload configuration, so this step is required for configuration changes to take effect.
