API rate limit configuration reference

Reference for configuring API rate limits in the scanner service.

Configuration file

File location: /etc/scanner/config.yml

Configuration section: api_settings

Configuration parameters

Parameter Type Default Description
custom_limits_enabled Boolean false Enables custom rate limit configuration. Must be set to true before CLI commands are accepted.
timeout Integer (seconds) 30 Request timeout value.
default_limit Integer (requests) 500 Default rate limit when custom limits are not applied.

Configuration example

api_settings:
  timeout: 30
  custom_limits_enabled: true
  default_limit: 500

CLI command

Apply custom rate limits using the scanner-cli command:

scanner-cli config update --api-limit <number> --window <seconds>

Where:

  • <number> is the maximum number of requests allowed
  • <seconds> is the time window in seconds

Example: scanner-cli config update --api-limit 1000 --window 60 limits requests to 1000 per 60-second window.

Error codes

Error code Message Cause
403 Rate limit configuration is disabled globally. custom_limits_enabled is set to false in /etc/scanner/config.yml
429 Too Many Requests The configured rate limit has been exceeded.

Service management

Service name: scanner-daemon

Restart the service after modifying the configuration file: sudo systemctl restart scanner-daemon

Configuration changes do not hot-reload; the service must be restarted.
