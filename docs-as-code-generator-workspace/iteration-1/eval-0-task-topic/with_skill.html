Configure Custom API Rate Limits

Learn how to set up custom rate limits for your API using the configuration file and CLI commands. This procedure enables you to control the number of requests your API accepts within a specified time window.

Prerequisites

  • Root or administrative access to the host server
  • Access to the global configuration file at /etc/scanner/config.yml
  • The scanner daemon must be restarted after configuration changes (the system does not hot-reload configuration)
  • The scanner-cli command-line tool must be available on your system

Steps

  1. Log into the host server as root.
  2. Open the global configuration file /etc/scanner/config.yml in a text editor.
  3. Locate the api_settings block and verify its current state: 
    api_settings:
  timeout: 30
  custom_limits_enabled: false
  default_limit: 500
  4. Set custom_limits_enabled to true and save the file: 
    api_settings:
  timeout: 30
  custom_limits_enabled: true
  default_limit: 500
  5. Restart the scanner daemon to apply the configuration change by running the following command: 
    sudo systemctl restart scanner-daemon
  6. Apply your custom rate limits using the CLI by running the following command, where <number> is the maximum number of requests and <seconds> is the time window: 
    scanner-cli config update --api-limit <number> --window <seconds>
    For example, to set a limit of 1000 requests per 60 seconds: 
    scanner-cli config update --api-limit 1000 --window 60

Expected Results

When you successfully apply the rate limit configuration, the CLI returns a 200 OK: Rate limits updated. response. You can verify that the rate limit is working correctly by sending requests to the API endpoint. When you exceed the configured limit, the API returns a 429 Too Many Requests HTTP response, indicating that the rate limit is active.

Troubleshooting

403 Forbidden Error When Configuring Rate Limits

If you receive a 403 Forbidden error with the message Error 403: Rate limit configuration is disabled globally., one of the following prerequisites is missing:

  • You did not modify the global YAML file at /etc/scanner/config.yml to set custom_limits_enabled: true.
  • You modified the file but did not restart the scanner daemon. The daemon must be restarted for the configuration change to take effect.

To resolve this error, complete steps 2–5 of the configuration procedure above, ensuring that you restart the daemon before running the CLI command.
