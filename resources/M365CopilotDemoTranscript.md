# Learning Basic HTML with Microsoft 365 Copilot Chat

## Introduction

HTML (HyperText Markup Language) is the standard language used to build web pages. If you're new to web development, Microsoft 365 Copilot Chat is a fast way to learn the basics — you can ask it plain-language questions and get both explanations and working code examples in return.

This guide walks you through using Copilot Chat to learn what HTML is, generate a working example, and understand the individual elements that make it up. By the end, you'll be able to ask Copilot to explain any HTML element you come across and generate your own sample pages.

## Prerequisites

Before you start, make sure you have:

- **Access to Microsoft 365 Copilot Chat** — You'll need this open to type questions and receive responses.
- **Basic familiarity with chat interfaces** — No prior HTML knowledge is required.

## Procedure

### Task 1: Get a Definition of HTML

Start from the Copilot home page and ask a foundational question to learn what HTML is before going any further.

**Step 1: Open the Copilot chat box**
Go to the Copilot home page and locate the chat box.

Expected result: The chat box is open and ready to accept a question.

**Step 2: Ask what HTML is**
Type the following into the chat box:

```
What is HTML?
```

> **Technical detail:** HTML stands for HyperText Markup Language — it's the standard language used to build web pages.

Expected result: Copilot responds with an explanation similar to: "HTML stands for HyperText Markup Language. It is the standard language used to build web pages."

### Task 2: Generate a Simple HTML Example

Once you understand what HTML is, ask Copilot to show you a working example so you can see the concept in practice.

**Step 1: Ask for a simple HTML example**
Type the following into the chat box:

```
Show me a simple HTML example.
```

Expected result: Copilot generates a complete basic HTML page structure:

```html
<html>
<head>
<title>My First Page</title>
</head>
<body>
<h1>Hello World</h1>
<p>This is my first webpage.</p>
</body>
</html>
```

### Task 3: Explain Individual HTML Elements

Dig deeper into the example Copilot generated by asking it to explain specific elements, one at a time.

**Step 1: Ask Copilot to explain the h1 element**
Type the following into the chat box:

```
Explain the h1 element.
```

> **Note:** The h1 element defines the primary heading on a web page.

Expected result: Copilot responds with: "The h1 element defines the primary heading on a web page."

**Step 2: Ask about the difference between h1 and h2**
A common follow-up question once you understand the basics is how h1 and h2 differ. Ask:

```
What's the difference between h1 and h2?
```

> **Note:** h1 represents the primary page heading, while h2 elements create subsection headings.

Expected result: Copilot responds with: "The h1 element represents the primary page heading. h2 elements create subsection headings."

### Task 4: Continue Learning with Follow-up Questions

Build on what you've learned to generate more complete examples and understand why the code works the way it does.

**Step 1: Ask for a complete sample page using headings and paragraphs**
Type a request such as:

```
Generate a complete sample web page using headings and paragraphs.
```

Expected result: Copilot generates a fuller HTML page example that combines headings and paragraphs into one page.

**Step 2: Ask Copilot to explain why the code works**
Type a request such as:

```
Explain why this code works.
```

Expected result: Copilot explains the structure and behavior of the generated code. You can keep asking follow-up questions until you understand each element.

## Expected Results

### What You Should See

By completing this guide, you'll have:
- A clear definition of what HTML is and what it's used for
- A working HTML example generated by Copilot
- An understanding of the h1 and h2 heading elements and how they differ
- The ability to generate and understand a complete sample web page using Copilot

### Validation

- [ ] Copilot correctly defined HTML as HyperText Markup Language
- [ ] Copilot generated a valid HTML page structure with `<html>`, `<head>`, and `<body>` tags
- [ ] Copilot explained the difference between the h1 and h2 elements
- [ ] You generated a sample page combining headings and paragraphs

### Troubleshooting

**Issue: Copilot's response doesn't include code formatting**
- This can happen if the question is phrased ambiguously.
- Solution: Ask explicitly, e.g., "Show me the HTML code for a simple page," so Copilot recognizes you want a code example.

**Issue: You don't understand an element Copilot used**
- This is expected as you're just getting started with HTML.
- Solution: Ask a direct follow-up question, such as "Explain the `<p>` element," and continue until each part of the example is clear.
