# Learning Basic HTML with Microsoft 365 Copilot Chat

## Introduction

HTML (HyperText Markup Language) is the standard language used to build web pages. If you're new to HTML, you don't need to memorize syntax from a textbook — you can learn it interactively by asking Microsoft 365 Copilot Chat questions and requesting live examples.

This guide walks you through using Copilot Chat to get a definition of HTML, generate a working page example, and understand individual elements like `h1` and `h2`. By the end, you'll know how to keep asking follow-up questions to build your understanding of any HTML element you encounter.

## Prerequisites

Before you start, make sure you have:

- **Access to Microsoft 365 Copilot Chat** — you'll type your questions directly into the chat box.
- **Basic familiarity with chat interfaces** — no HTML knowledge is required going in.

## Procedure

### Task 1: Ask Copilot what HTML is

Start with the question anyone new to HTML would ask first — what HTML actually is.

**Step 1: Ask for a definition**
From the Copilot home page, type `What is HTML?` into the chat box.

Expected result: Copilot responds that HTML stands for HyperText Markup Language and is the standard language used to build web pages.

### Task 2: Ask Copilot for a simple HTML example

A definition is useful, but seeing HTML in action makes it click faster.

**Step 1: Request an example**
Type `Show me a simple HTML example.`

Expected result: Copilot generates a complete HTML page structure, including the `html`, `head`, `title`, `body`, `h1`, and `p` elements:

```html
<html>
<head>
<title>My First Page</title>
</head>
<body>
<h1>Hello World</h1>
<p>This is my first webpage.</p>
</body>
</html>
```

> **Note:** Copilot returns the entire page structure, not just a snippet — this gives you a working example you can reference for future pages.

### Task 3: Explore individual HTML elements

Once you have a working example, dig into what each element actually does.

**Step 1: Ask about a specific element**
Type `Explain the h1 element.`

Expected result: Copilot explains that the `h1` element defines the primary heading on a web page.

**Step 2: Compare related elements**
Ask Copilot the difference between `h1` and `h2`.

Expected result: Copilot explains that `h1` represents the primary page heading, while `h2` elements create subsection headings.

### Task 4: Continue learning with follow-up questions

Once you understand the basics, use follow-up questions to build more complete pages and understand why the code works the way it does.

**Step 1: Generate a fuller example**
Ask Copilot to generate a complete sample web page using headings and paragraphs.

Expected result: Copilot generates a fuller HTML page example combining multiple heading and paragraph elements.

**Step 2: Ask Copilot to explain the code**
Ask Copilot to explain why the generated code works.

Expected result: Copilot explains the purpose and behavior of each element in the generated code, so you understand it rather than just copying it.

## Expected Results

### What You Should See

By completing this guide, you'll have:

- A clear definition of HTML and what it's used for
- A working HTML page example generated by Copilot
- An understanding of the `h1` and `h2` elements and how they differ
- The ability to keep using follow-up questions to learn new HTML elements on your own

### Validation

- [ ] Copilot returned a definition of HTML
- [ ] Copilot generated a complete HTML page example
- [ ] You can explain the difference between `h1` and `h2`
- [ ] You know how to ask Copilot follow-up questions about any HTML element

### Troubleshooting

**Issue: Copilot's answer feels too high-level or vague**
- Ask a more specific follow-up question, such as "Explain the h1 element" rather than "Explain HTML elements."
- Request an example directly: "Show me a simple HTML example."

**Issue: You don't understand why the generated code works**
- Ask Copilot directly: "Explain why this code works."
- Keep asking follow-up questions about individual elements until each one makes sense.
