Create a subtask in Jira

Create a subtask under an existing issue to break down work into smaller, manageable pieces. You can create a new subtask or link an existing work item.

Prerequisites

  • You have write access to the issue
  • You are in an open Jira issue

Create a subtask

  1. Navigate to the issue where you want to add a subtask.

    Jira displays the issue details page with the Description, Subtasks, and other sections visible.

  2. In the Subtasks section, select the + button next to the section title.

    A menu opens displaying options including Create subtask, Link work item, Add attachment, and other actions.

  3. Select Create subtask from the menu.

    The Subtasks section expands and displays options for adding a subtask.

  4. (Optional) Review the AI-generated work item suggestions.

    If enabled, Jira displays a Create suggested work items section with recommended subtasks based on your issue context. You can select any suggestion or create a custom subtask instead.

  5. Choose your method for adding a subtask.

    Method 1: Create a new subtask

    In the Name this subtask field, enter a name for your new subtask. For example, enter Track the tokens used.

    Select the Create button to create the subtask.

    Method 2: Link an existing work item as a subtask

    Select Choose existing to link an existing work item to this issue as a subtask instead of creating a new one. This option is useful when you have related work already in progress that should be tracked as part of this issue.

  6. Confirm the subtask creation.

    Jira creates the subtask and displays a success notification. The new subtask appears in the Subtasks table with its issue key, priority, assignee, and status. The notification confirms the action, for example: You've created 'KAN-5' work item.

Result

The subtask has been created and is now visible in the Subtasks section of the parent issue. The new work item has its own issue key and can be tracked independently. You can assign it to team members, set priority and due dates, and link it to other work items.

Additional information

AI suggestions: Jira's draft generator feature uses AI to suggest subtasks based on your issue description and context. Review these suggestions to identify related work that should be tracked.

Linking existing work items: Use the Choose existing option to connect related work already in progress without creating duplicate tasks.

Edit subtask details: After creation, edit the subtask's assignee, priority, due date, labels, and other properties from the subtask's detail page.

Alternative method: You can also select Add subtask (text link) in the Subtasks section instead of using the + button. Both methods access the same create subtask form.
