### **Context**

The input document is a Microsoft Word Product Requirements and Specifications document for a software product.



The objective is to transform the source document into a professional HTML5 document suitable for browser preview or web publishing while preserving all the technical information, formatting, document hierarchy and logical flow.



The generated HTML should follow technical writing best practices and be suitable for future review, editing and publishing and technical documentation review.



### **Constraints**

* Read the complete Microsoft Word document.
* Do not omit any important technical information.
* Do not invent or modify technical content.
* Preserve the logical sequence of the document.
* Preserve original heading hierarchy.
* Preserve paragraphs, tables, lists, notes, warnings and cautions. 
* Preserve bold, italic, hyperlinks, code snippets and table formatting wherever applicable.
* Preserve document metadata such as document title, revision information and version number if applicable.
* Use semantic HTML5 elements wherever possible.
* Generate valid and standards-compliant HTML5.
* Maintain consistent terminology throughout the document.
* Follow technical writing best practices, including clear headings, concise language, consistent formatting and logical organization.
* If the information is incomplete or unclear, retain the original content and flag it for review rather than making assumptions. 
* Ensure that the output is clean, readable and suitable for technical documentation.
