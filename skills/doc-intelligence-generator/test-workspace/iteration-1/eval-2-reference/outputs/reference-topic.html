Advanced Search API Reference

Version: 2.0
Description: API for configuring and executing advanced search queries with semantic understanding and intelligent filtering

Overview

The Advanced Search API provides endpoints for executing search queries with natural language understanding and configurable filtering. Developers can integrate semantic search capabilities into their applications with support for intelligent filter suggestions, faceted result organization, and personalized ranking.

Search Endpoint: POST /api/v2/search

Execute a search query with optional filters and retrieve results ranked by relevance.

Request Parameters

Parameter Name Type Required Default Description
query string Yes — Search query in natural language or keywords. Maximum 500 characters. Example: "documents about security from last month"
filters object No null Optional filter object. Can include: document_type, date_range, author, tags. See filters configuration below.
limit integer No 20 Maximum number of results to return. Range: 1-100. Larger limits increase response time.
offset integer No 0 Pagination offset. Use for retrieving results beyond the first page. Example: offset=20 returns results 21-40.
sort string No relevance Sort order for results. Valid values: relevance, date_desc, date_asc, popularity
include_suggestions boolean No true Include AI-generated filter suggestions in response. Set to false to reduce response payload size.

Filter Configuration

The filters object supports the following properties:

Filter Property Type Values Description
document_type array of strings guide, api_reference, tutorial, faq Filter results by document type. Example: ["guide", "api_reference"]
date_range object from, to (ISO 8601 dates) Filter by publication date range. Example: {"from": "2024-01-01", "to": "2024-12-31"}
author string Author name or ID Filter results by document author. Example: "Jane Smith"
tags array of strings Any custom tag values Filter by document tags. Example: ["security", "authentication"]

Server Configuration Options

Configure the search service behavior using the following parameters:

Search Engine Configuration

Configuration Type Default Valid Values Description
search_engine string elasticsearch elasticsearch, opensearch, meilisearch Underlying search backend engine. Elasticsearch recommended for large deployments.
semantic_model string multilingual-e5-large multilingual-e5-large, all-mpnet-base-v2, bge-large-en-v1.5 ML model for semantic understanding. Multilingual-e5 recommended for international deployments.
timeout_ms integer 5000 1000–30000 Query timeout in milliseconds. Increase for large datasets or slow networks.

Ranking and Filtering

Configuration Type Default Range Description
min_relevance_score number 0.5 0.0–1.0 Minimum relevance threshold for results. Higher values exclude less relevant matches.
enable_personalization boolean true true, false Enable personalized ranking based on user behavior. Improves result quality over time.

Caching Configuration

Configuration Type Default Range Description
cache_results boolean true true, false Cache popular search results for improved performance. Reduces backend load.
cache_ttl_seconds integer 3600 60–86400 Time-to-live for cached results in seconds. Default: 1 hour. Increase for stable content.

Example Request

POST /api/v2/search
Content-Type: application/json

{
  "query": "security best practices",
  "filters": {
    "document_type": ["guide", "reference"],
    "date_range": {
      "from": "2024-01-01",
      "to": "2024-12-31"
    }
  },
  "limit": 10,
  "sort": "relevance",
  "include_suggestions": true
}

Example Response

{
  "results": [
    {
      "id": "doc-12345",
      "title": "Security Best Practices Guide",
      "relevance_score": 0.95,
      "snippet": "This guide covers essential security practices including authentication, authorization, and encryption..."
    }
  ],
  "total_results": 24,
  "suggestions": [
    {
      "filter_type": "document_type",
      "suggested_value": "guide",
      "confidence": 0.87
    }
  ]
}
