Setting Up Advanced Search with AI-Powered Filters

Overview

This guide walks you through enabling and configuring the Advanced Search feature with AI-powered semantic understanding and intelligent filtering. After completing these steps, your users will have access to natural language search with automatic filter suggestions, faceted result browsing, and personalized ranking. The setup process takes approximately 30 minutes and requires administrator access to your system.

Prerequisites

Before you begin, ensure you have the following in place:

  • Administrator access to your platform with settings and configuration permissions
  • Basic understanding of search concepts and machine learning models
  • Access to the system Administrator Dashboard and configuration panels
  • System requirements: Python 3.8 or higher available on your server
  • Disk space: Approximately 2 GB available for ML model files
  • Network connectivity: Access to model repositories for downloading language models

Step-by-Step Instructions

  1. Log in to the Administrator Dashboard. Open your browser and navigate to the admin console. Enter your administrator credentials. Verify successful login.
    📸 Screenshot Placeholder Step 1: Log in to Administrator Dashboard Insert screenshot showing the login page with username/password fields and login button
  2. Navigate to Advanced Search Settings. From the main dashboard menu, select Settings → Advanced Features → Search Configuration. The configuration panel loads.
    📸 Screenshot Placeholder Step 2: Navigate to Search Configuration Insert screenshot showing the Settings menu navigation path with dropdown menus highlighted
  3. Enable the Semantic Search Engine. In the Search Configuration panel, locate the toggle labeled "Semantic Search Engine". Click to enable it (toggle turns blue). Confirmation message appears: "Semantic search engine initialization started".
    📸 Screenshot Placeholder Step 3: Enable Semantic Search Engine Insert screenshot showing the toggle switch in OFF position, then in ON position (blue), showing the Settings panel
  4. Select a Machine Learning Model. After enabling semantic search, a dropdown menu appears. Choose your model:
    1. multilingual-e5-large — Recommended for multiple languages
    2. all-mpnet-base-v2 — Recommended for English-only deployments
    3. bge-large-en-v1.5 — Recommended for maximum accuracy
    Select multilingual-e5-large for most deployments.
    📸 Screenshot Placeholder Step 4: Select ML Model from Dropdown Insert screenshot showing the ML Model dropdown menu expanded with the three options visible
  5. Configure Query Timeout. Enter a timeout value in milliseconds:
    • Standard: 5000 (5 seconds)
    • Large datasets: 10000 (10 seconds)
    • Very large: 15000 (15 seconds)
    Press Tab to confirm.
  6. Enable Filter Suggestions. Check the box labeled "Enable Smart Filter Suggestions". This allows automatic filter suggestion based on search queries.
    📸 Screenshot Placeholder Step 6: Enable Filter Suggestions Checkbox Insert screenshot showing the checkbox for "Enable Smart Filter Suggestions" in both unchecked and checked states
  7. Set Minimum Relevance Score. Use the slider to set the threshold (0.0–1.0):
    • Conservative (strict filtering): 0.7 or higher
    • Balanced (recommended): 0.5
    • Permissive (more results): 0.3 or lower
  8. Enable Personalization. Check "Enable Personalized Ranking" to adapt results based on user behavior over time.
  9. Review All Settings. Verify all configuration is correct before saving.
  10. Save Configuration. Click the blue "Save Configuration" button. A progress indicator appears. Wait for confirmation: "✓ Configuration saved successfully".
    📸 Screenshot Placeholder Step 10: Click Save Configuration Button Insert screenshot showing the blue "Save Configuration" button and the progress indicator during save
  11. Run System Test. After saving, click "Run System Test". The system verifies:
    • Semantic search engine responding
    • ML model loaded and ready
    • Filter suggestion service operational
    • Cache layer functional
    Wait 30-60 seconds for results.
    📸 Screenshot Placeholder Step 11: Run System Test Insert screenshot showing the "Run System Test" button and the test progress/results panel
  12. Verify Test Results. Successful setup shows:
    • ✓ Semantic search engine initialized successfully
    • ✓ ML model loaded and ready for inference
    • ✓ Filter suggestion service operational
    • ✓ System ready for user searches
    📸 Screenshot Placeholder Step 12: Verify Test Results Insert screenshot showing successful test results with green checkmarks for all 4 tests

Post-Setup Verification

After completing setup, perform these verification steps:

Test Basic Search

  1. Try this search: "documents about security from last month"
  2. Verify results appear within 1-2 seconds
  3. Verify filter suggestions appear below search box
  4. Click a suggested filter and verify results update

Success Criteria

✓ Setup is successful when:
  • Natural language queries are understood and return relevant results
  • Filter suggestions appear within 500 milliseconds
  • All suggested filters work correctly
  • Search results display with relevance scores
  • No errors in system logs

Next Steps
